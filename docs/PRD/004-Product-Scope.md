# 1. Purpose

This document defines the product scope of ClipStudio AI.

It establishes:

- included capabilities
- excluded capabilities
- development priorities

---

# 2. Product Scope Philosophy

ClipStudio AI focuses on:

```
Automatic Video Discovery

+

AI Clip Generation

+

Human Review
```

---

# 3. Product Scope Overview

The product consists of:

```
Agent System

Discovery System

AI Analysis

Clip Generation

Rendering

Review Workflow

Automation
```

---

# 4. MVP Scope

Version 1.0 must include:

```
AI Agent Creation

Video Discovery

Transcript Extraction

AI Analysis

Clip Selection

Segment Download

Subtitle Generation

Watermark

Rendering

Review Dashboard
```

---

# 5. Feature Scope

---

# 5.1 AI Agent System

Included:

✓ Create agent

✓ Enable/disable agent

✓ Configure category

✓ Configure source

✓ Configure watermark

✓ Configure schedule

---

# 5.2 Video Discovery

Included:

✓ Search video sources

✓ Extract metadata

✓ Identify candidates

✓ Store source information

---

# 5.3 Transcript Pipeline

Included:

✓ Extract audio

✓ Generate transcript

✓ Generate timestamps

✓ Support subtitle creation

---

# 5.4 AI Analysis

Included:

✓ Understand content

✓ Detect important moments

✓ Generate clip candidates

✓ Explain selection reason

---

# 5.5 Scoring Engine

Included:

✓ Engagement prediction

✓ Emotional scoring

✓ Quality scoring

✓ Ranking

---

# 5.6 Segment Downloader

Included:

✓ Timestamp-based download

✓ Partial video extraction

✓ Avoid full video download

---

# 5.7 Rendering System

Included:

✓ Video cutting

✓ Subtitle rendering

✓ Watermark

✓ Export format

---

# 5.8 Review System

Included:

✓ Preview clips

✓ Approve clips

✓ Reject clips

✓ Export clips

---

# 6. Excluded From MVP

The following are NOT included initially:

---

## Automatic Publishing

Not included:

```
Auto upload to TikTok

Auto upload YouTube

Auto upload Instagram
```

Reason:

Human approval required.

---

## Cloud Processing

Not included:

```
Mandatory cloud AI
```

Reason:

Local-first architecture.

---

## Multi User System

Not included:

```
Team accounts

Permissions

Collaboration
```

---

## Mobile Application

Not included:

```
Android

iOS
```
